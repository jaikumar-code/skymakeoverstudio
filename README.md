# Sky Makeover Studio

Luxury bridal artistry and bespoke makeover experience landing page.

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- App Router

## Local setup

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Production build

```bash
npm run build
npm start
```

## Deploy

This project can be pushed directly to GitHub and deployed to Vercel or another Next.js compatible host.

The current imagery uses Unsplash remote image URLs.
